# Student Result Management System

A web-based Student Result Management System built using Python, Flask and MySQL.

## Features

- Admin login authentication
- Add students
- Add results
- Automatic grade calculation
- Student rank list generation
- MySQL database integration

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- Bootstrap

## Project Structure

student_result_system/
│
├── app.py
├── db.py
└── templates/

## Run the Project

1. Open VS Code
2. Open terminal
3. Run:

python app.py

4. Open browser:

http://127.0.0.1:5000
